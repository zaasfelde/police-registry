# Сторонние компоненты

## QR Code generator library (C++)

- Файлы: `src/third_party/qrcodegen.hpp`, `src/third_party/qrcodegen.cpp`
- Автор: Project Nayuki
- Лицензия: MIT
- Источник: https://www.nayuki.io/page/qr-code-generator-library

Библиотека используется только для генерации QR-кода с `otpauth://`-ссылкой
при настройке двухфакторной аутентификации. Текст лицензии MIT сохранён в
шапке обоих файлов.

## Qt 6

Проект использует Qt Core, Gui, Qml, Quick, Sql и Network под лицензией,
выбранной при установке Qt (LGPL/GPL/коммерческая).
